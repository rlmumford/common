# Named checklist templates

Actual Drupal 10/Claro screenshots captured with Playwright at 1440×1050 and
opened for visual inspection. No mock HTML or generated artwork.

To reproduce: edit a job, open Checklist templates, add `appointment` labelled
“Appointment preparation”, and add a Simple Checkbox item named
`check_documents`. Switch to Checklist, select Appointment preparation, and Apply
to draft. Save commits both definitions and references. The two images show the
named definition editor and its static inclusion on the Checklist tab.
