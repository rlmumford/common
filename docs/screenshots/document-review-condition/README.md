# Current-review condition

Actual Playwright Chromium capture from the local Drupal 10 DDEV site. The new
native condition is selected in a fictional job's assignment-rule form, with the
standard Typed Data Plus document selector and normal negation control.

The image was opened and visually inspected. The browser then saved the rule to
the job draft and verified it appeared in the assignment table. Kernel tests cover
condition execution, review outcomes as contexts, new revisions and denied access.
